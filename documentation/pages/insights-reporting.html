From signal to action

Insights and reporting

Privacy Analytics connects detection, explanation, communication, and follow-up. These tools help a team move from a changed number to a documented decision.

▶

Start with a saved segment or an investigation, add timeline context, set a KPI target, and create an alert for changes that need attention.

Annotations

Add product releases, campaigns, incidents, experiments, or content launches to the analytics timeline. A short, specific annotation often explains a chart faster than a separate document. Include what changed and who can provide context.

Saved segments

In Decision center, save reusable audiences using source, page, device, country, event, or campaign. Match with equals, contains, starts with, or does not contain. Segments keep recurring comparisons consistent across investigations.

Investigations

An investigation compares the current period with the previous period and ranks the dimensions that contributed most. Choose a question, metric, breakdown dimension, and a 7-, 30-, or 90-day period.

Investigations support pageviews, visitors, sessions, and events with source, page, device, country, event, or campaign breakdowns. Close an investigation when the explanation is sufficient or the issue no longer needs follow-up.

KPI board

Create weekly, monthly, or quarterly targets from numeric native or blended metrics. Each KPI shows current value, expected pace, progress, forecast, direction, unit, and owner. “Higher is better” fits growth metrics; “lower is better” fits costs, failures, or response times.

Decision log

Record the action, rationale, owner, due date, and linked investigation. Comments keep follow-up beside the evidence. Resolve the record when the action is complete or intentionally closed.

Email alerts

Open Email alerts for a site. Each teammate manages their own subscriptions. Available signals include:

  • Traffic drops and traffic spikes.
  • Sharp changes on an important page.
  • A conversion-rate decline.
  • An important conversion event stopping.
  • All tracking stopping for more than 24 hours.

Alerts run hourly and include minimum-volume safeguards so small random changes do not create unnecessary mail. Use Email previews to inspect every template before enabling delivery.

Scheduled dashboard reports

A scheduled report sends an established dashboard to a chosen audience on a recurring schedule. Use it for leadership briefs, campaign updates, product reviews, or operational summaries. The email contains a compact view of every configured tab for the last 30 days; charts may need the full dashboard for detail. Follow the email-report tutorial to check the recipient, delivery path, and ongoing usefulness.

Data quality

Open Data quality before trusting an unexpected trend. It scores event collection, recent volume, daily aggregation, conversion setup, and connected-source freshness. A healthy source does not guarantee the metric definition is correct, so review both connection health and field meaning.

System health

System administrators can open System health to verify database connectivity, queue and scheduler heartbeats, event volume, aggregation, conversions, and connected sources. Resolve worker or scheduler failures before treating missing report data as user behavior.

Recommended workflow

  1. Detect.

    Use Overview, Insights, alerts, and KPI status to find material movement.

  2. Validate.

    Check data quality, date completeness, bot classification, and known annotations.

  3. Explain.

    Use segments, Explore, journeys, funnels, and investigations.

  4. Decide.

    Record the action, owner, due date, and evidence in Decision center.

  5. Communicate.

    Update the dashboard or scheduled report that the relevant team already follows.
