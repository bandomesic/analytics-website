Flexible reporting

Custom dashboards

Build one focused view for each team or question. Dashboards can mix native analytics, explorations, external metrics, calculated fields, and blended metrics without tying a block to one future data provider.

▶

Follow the full reporting path: build a useful dashboard, share it safely, and schedule a useful email report.

Create a dashboard

Open a site and choose Custom dashboards. Start from Executive, Product, Content, or Campaign structure, give the dashboard a clear name, and then enter edit mode.

Organize with tabs

Tabs divide a broad dashboard into purposeful views such as Overview, Acquisition, Product, Revenue, or Operations. Use the settings icon beside the active tab to rename it. Drag tabs by their handle to change the order.

A dashboard is easier to scan when every tab answers one related set of questions. Avoid creating one tab per metric.

Add blocks

In the right settings panel, choose a data source and then a metric. The available display types depend on the metric shape:

Metric shapeAvailable displaysTypical use
NumberNumber cardVisitors, revenue, conversion rate, target progress
Time seriesLine or bar chartTraffic, engagement, or revenue over time
CategoryTable, bar, or donut chartSources, pages, devices, countries
TableTableCampaigns, funnels, detailed business rows

Edit a block

Select Edit on a block. The block receives a visible highlight and the full-height inspector identifies exactly what you are editing. Changes to title, description, display, size, row count, target, color, and destination tab preview live before you save.

Use the canvas controls to resize, duplicate, reorder, move, or remove a block. Small blocks are suited to scorecards; charts should normally use medium or full width.

Date and source filters

The dashboard date range is shared by blocks that support time filtering. A global source filter can focus the canvas on one provider. Individual external datasets use their configured date column; datasets without one show an all-time value.

Versions, undo, and restore

Dashboard changes create versions. Use undo while editing or restore an earlier saved version when a layout or configuration no longer works. Version history also provides a useful audit trail for shared team dashboards.

Share a dashboard

Use Share & report below a dashboard to create an expiring read-only link for 7, 30, or 90 days. Add a password when the report should be available outside the signed-in workspace but still protected. The shared view currently shows the last 30 days. There is no per-link revoke control in the current interface, so choose an expiry that fits the audience and purpose before creating the link.

!

A share link exposes the dashboard data rendered by that link. Treat the URL and password as credentials, and review every tab before sharing it outside the organization.

Export and schedule

Export a 30-day CSV for offline use, or create a weekly or monthly email schedule. Scheduled emails show a compact, last-30-days rendering of configured tabs and blocks, so recipients can read the summary without signing in. The Open dashboard link still requires workspace access. Configure a real mail transport and running scheduler and worker before relying on delivery; the listed sent time means the report was queued, so confirm arrival in the inbox.

Dashboard design guidance

  • Start each tab with two to four outcome scorecards.
  • Place a trend directly after its headline number.
  • Use breakdowns to explain the movement, not to fill space.
  • Give external metrics a source-aware title and description.
  • Use targets only when the team owns the target and review period.
  • Schedule a report only after the interactive dashboard is understandable without narration.
