Using the app

Analytics reports

The standard reports move from “what changed?” to “who and what contributed?” and finally to “what should we do next?” Use the same date range while moving between sections so the story remains comparable.

▶

For an ordered journey with real events, follow Build an ordered funnel. It covers step definitions, a valid test session, and interpreting drop-off.

Date ranges and comparison

Use the date control on a report to select Today, Yesterday, Last 7 days, Last 30 days, Last 90 days, Last 365 days, This month, Last month, or a custom range. When comparison is enabled, charts and changes use the equivalent previous period.

Daily rollups use UTC. Very recent events may appear first in realtime views and then in aggregated reports after background processing.

Overview

Overview is the daily starting point. It combines pageviews, estimated visitors, sessions, engagement, conversions, traffic trends, top pages, and top sources. Use it to find the signal that deserves a deeper report.

Audience

Audience explains the shape of traffic:

  • Geography uses the locally installed GeoIP database when available.
  • Devices groups device type, browser, and operating system.
  • Pages and page groups show where attention is concentrated.
  • Traffic quality separates human, probable bot, monitoring, internal, and unknown traffic.

Acquisition

Acquisition shows how visits begin. Referrers are classified into direct, organic, social, email, paid, and referral traffic. Campaign tables use standard UTM parameters so teams can compare source, medium, and campaign consistently.

Use this page to evaluate channel mix, campaign reach, and landing-page quality. A traffic increase is more useful when the next reports show whether those visitors engaged or converted.

Engagement

Engagement combines active time and meaningful browser interactions. It helps distinguish a loaded page from a page someone actually used. Review event totals, engagement trends, and content performance together.

Goals and funnels

Conversions count the important events defined for a site and calculate rates against eligible sessions. Funnels show how many sessions reached each ordered page or event step, including completion rate and drop-off between steps.

Insights

Insights highlights notable movement so you do not need to scan every table manually. Treat an insight as a starting point: confirm it against the relevant report, segment, date range, and known business context before acting.

Explore

Explore is the ad hoc analysis workspace. Choose a metric, dimension, filters, and date range to answer a specific question. Useful explorations can be saved as dashboard blocks, which turns one-time analysis into a repeatable report.

Journeys

Journeys reveal common sequences of pages and events. Use them to understand entry paths, movement toward an outcome, and where sessions stop. Combine journey patterns with a focused funnel when the order matters to the product decision.

Retention

Retention groups sessions into cohorts and shows whether visitors return in later periods. Compare product releases, acquisition channels, or important audience segments over time rather than relying on one aggregate return rate.

Object Analytics

Object Analytics is optional and uses types that you define. It compares impressions, views, interactions, clicks, conversions, shares, saves, reach, surfaces, placements, and year-over-year performance for individual objects. Use it when a page-level total cannot answer which specific item performed best. Continue with the Object Analytics guide for setup and reporting details.

Reading reports responsibly

  • Check data quality before explaining a sudden change.
  • Use a complete period when comparing daily or weekly performance.
  • Separate internal and bot traffic from the customer story.
  • Add annotations for launches, campaigns, incidents, and experiments.
  • Record a decision only after the evidence and expected outcome are clear.

A practical analysis pattern

  1. Start with movement.

    Use Overview and comparison to identify the metric and dates that changed.

  2. Break down the change.

    Move to Acquisition, Audience, Engagement, or Explore while keeping the same period.

  3. Check behavior.

    Use funnels and journeys to see whether people reached the intended outcome.

  4. Validate the data.

    Check annotations, traffic quality, collection health, and period completeness.

  5. Make the finding repeatable.

    Save the exploration to a dashboard, create an alert or KPI, and record the decision.
