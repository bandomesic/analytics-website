Before you start

The object-data overview needs no setup. Complete these once for hands-on tracking tutorials; reporting tutorials can use a site that already has data.

  1. 1
    Add your website

    Open Sites, select Add site, and enter the exact public URL including https://.

  2. 2
    Install the base tracker

    Copy the single script shown on the site page into your website. Most tutorials need no further website deployment; use a stable existing selector for interaction rules.

  3. 3
    Confirm the connection

    Visit your website once, return to the site page, and wait until the status says Tracker connected.

Keep two tabs open: this tutorial and your Privacy Analytics workspace. The examples use sample paths and names; replace them with real values from your website. Owners and administrators can create rules, sources, and dashboards; viewers can follow the analysis steps.

Tutorial 20

Turn a CSV into a metric

Upload a private snapshot, define a numeric metric, and use it in a dashboard.

◷ Self-paced
Step 1 of 6

Prepare a small, clear file

A useful CSV has one header row and one meaning per column.

  1. Use unique column names such as date and revenue.
  2. Use ISO dates such as 2026-09-23 when you want dashboard date filtering.
  3. Remove personal data that the dashboard does not need.
  4. Keep the file under 5 MB and 100,000 rows.
Check before continuingThe revenue column contains numeric values and the date column is consistent.

✓Numeric values

Step 2 of 6

Upload it to the right site

The upload creates a private source and an initial row-count metric.

  1. Open the site’s Site settings and scroll to Connected data.
  2. Expand CSV file under Add a data source.
  3. Enter a Source name, choose the CSV file, and set Date column (optional) if your file has one.
  4. Select Upload CSV.
Check before continuingThe source appears with a row and column count; without a date column, all rows apply to every dashboard range.

✓CSV file

Step 3 of 6

Check the imported shape

Verify the source before building calculations on top of it.

  1. Read the displayed row count and column names.
  2. Open Inspect source → to preview the imported columns and sample rows.
  3. If the data shape is wrong, correct the file before adding metrics.
Check before continuingThe source has the expected columns and representative values.

✓Columns

Step 4 of 6

Define the first business metric

The automatic row count is useful for volume, but most dashboards need a numeric field.

  1. In the source dataset, expand Add metric.
  2. Set Metric name to Revenue and Formula key to revenue.
  3. Choose Sum and the numeric CSV column revenue.
  4. Select Add metric.
Check before continuingThe dataset lists Revenue with a sum of the intended column.
✓Metric name
✓Sum
3Revenue column
Step 5 of 6

Use it in a dashboard

A metric becomes useful when it answers a recurring question.

  1. Open Dashboards for the same site.
  2. Create a dashboard or open one you manage, then enter edit mode.
  3. Select your CSV source in Data source, add a suitable number or trend block, and choose the new metric.
  4. Set a date range that includes the CSV dates.
Check before continuingThe block shows a value that agrees with a manual spot-check of the file.
✓Dashboard
✓CSV source
3Spot-check
Step 6 of 6

Refresh the snapshot safely

A replacement file must keep the columns existing metrics use.

  1. In Connected data, expand Replace CSV file for this source.
  2. Confirm the new file still has the revenue column and any date column.
  3. Upload it, then revisit the dashboard with the same date range.
  4. If the number changed unexpectedly, check file rows and date coverage first.
You are done whenThe updated metric reflects the new file without losing its field definitions.

Tutorial 21

Blend two metrics responsibly

Combine a connected revenue metric with native visitors and verify the result.

◷ Self-paced
Step 1 of 7

Name the question and units

A blend should answer a useful question with compatible numeric inputs.

  1. Use a question such as “How much revenue did we record per estimated visitor?”
  2. Choose a connected Revenue metric and native Visitors metric for the same site.
  3. Decide whether the result should be a currency amount per visitor.
Check before continuingYou know the numerator, denominator, and unit before opening the form.
✓Revenue
✓Visitors
3Currency per visitor
Step 2 of 7

Check both source periods

A correct division can still mislead when its inputs cover different dates.

  1. Inspect the connected dataset’s Date column in Site settings.
  2. Confirm Revenue has numeric values and covers the period you intend to analyze.
  3. Confirm the native Visitors report covers that same period.
Check before continuingA dataset without a date column is all-time and should not be compared as if it matched a selected month.
✓Date column
✓Numeric revenue
3Matching coverage
Step 3 of 7

Open Data blends

The Decision center combines two numeric metrics without changing their original definitions.

  1. Open Decision center → Data blends.
  2. Expand + Create blended metric.
  3. Enter Name Revenue per visitor and Key revenue_per_visitor.
Check before continuingThe name describes the calculation and the key is stable for later dashboard use.
✓Decision center
✓Name
3Key
Step 4 of 7

Choose the operands in order

For division, swapping the inputs changes the meaning.

  1. Set First metric to the connected Revenue metric.
  2. Choose Divide for Operation.
  3. Set Second metric to Privacy Analytics Visitors.
  4. Choose Currency for Unit and select Create blend.
Check before continuingThe saved definition reads Revenue ÷ Visitors, not Visitors ÷ Revenue.
✓First metric
✓Divide
3Second metric
Step 5 of 7

Sanity-check the result

Check a simple example before treating a ratio as a business conclusion.

  1. Find the new entry under Data blends and inspect its source names and operator.
  2. For a complete period, divide a known revenue total by the visitor estimate manually.
  3. If the denominator is zero or a source has no value, do not describe an empty result as zero performance.
Check before continuingThe displayed order and approximate magnitude agree with the source numbers.

Step 6 of 7

Use it in a dashboard

A blended metric becomes available as a reporting block.

  1. Open a dashboard for the same site and enter edit mode.
  2. Choose the blended source and the new metric from the available blocks.
  3. Give the block a title that includes the period and unit.
  4. Compare its value with the two source metrics for the same dates.
Check before continuingA teammate can identify both inputs and understand what one unit of the result means.
✓Dashboard block
✓Period
3Two inputs
Step 7 of 7

Keep the meaning stable

A ratio is only comparable while both sides retain the same definition.

  1. Document any currency conversion or refund treatment outside the blend if relevant.
  2. Check source freshness before trusting a sudden change.
  3. If the business question changes, create a new named blend instead of silently reusing this key.
  4. Continue with KPI targets only if a target for this metric would be meaningful.
You are done whenThe blend has a clear formula, aligned coverage, and an interpretation your team can repeat.

Tutorial 22

Set a KPI target you can interpret

Choose a metric, period, direction, and owner, then read pace and forecast.

◷ Self-paced
Step 1 of 6

Choose an owned outcome

A KPI should represent a number someone can influence or act on.

  1. Use one real goal, such as 10,000 estimated visitors this month.
  2. Confirm Visitors is already populated in Audience or Overview.
  3. Choose a target based on a known baseline rather than a round number alone.
Check before continuingYou can name the owner, target, and review period before creating the card.
✓Metric
✓Baseline
3Owner
Step 2 of 6

Open the target form

KPI targets live in the site’s Decision center.

  1. Open Decision center → KPI board.
  2. Expand + Create KPI target.
  3. Enter a specific Name such as Monthly visitors.
  4. Choose Visitors under Metric.
Check before continuingThe selected metric is numeric and matches the outcome in the title.
✓KPI board
✓Name
3Metric
Step 3 of 6

Set the target and direction

Direction changes how progress is judged.

  1. Enter the agreed Target, such as 10000.
  2. Choose Monthly for Period.
  3. Choose Higher is better and Number for Unit.
  4. Select the responsible person under Owner, then Create target.
Check before continuingThe card can be read as visitors toward a monthly target, not a percentage or currency amount.
✓Target
✓Monthly
3Higher is better
Step 4 of 6

Read the card in context

The card compares the current value with target and expected pace.

  1. Read the current value and target together.
  2. Compare the filled progress track with its expected-pace marker.
  3. Treat Forecast as an estimate of the period end, not a promise.
  4. Check whether the period is still early before reacting to a small gap.
Check before continuingYou can explain whether progress is ahead or behind pace and how uncertain the forecast is.
✓Current value
✓Expected pace
3Forecast
Step 5 of 6

Check the underlying report

A target cannot repair an incomplete or mismatched metric.

  1. Open Overview or Audience for the same site and calendar period.
  2. Check the Visitors definition and any data-quality warning.
  3. If the KPI uses a blended metric, also check both source date ranges and units.
Check before continuingThe KPI value agrees with the underlying metric for a comparable period.
✓Same period
✓Metric definition
3Data quality
Step 6 of 6

Review or retire the target

Targets should be revisited when the period or responsibility changes.

  1. Review the card with its owner at the chosen weekly, monthly, or quarterly cadence.
  2. Record a decision if the team changes course.
  3. If the KPI no longer measures a useful outcome, use Remove instead of leaving an obsolete target visible.
You are done whenThe board contains goals that still have an owner and a clear response to missed pace.
