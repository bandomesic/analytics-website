Configuration reference

Environment variables

The .env file defines the public URL, secrets, infrastructure connections, mail delivery, retention, and optional GeoIP updates. Keep production values outside version control and include them in an encrypted backup.

i

After changing production configuration, recreate the affected containers and rebuild Laravel's configuration cache with php artisan optimize.

Application and URL

Proxy and session

VariablePurpose
TRUSTED_PROXIESPrivate address or CIDR of the reverse proxy. Avoid * when the backend can be reached directly.
SESSION_DRIVERUse redis in the supplied production stack.
SESSION_LIFETIMEAuthenticated session lifetime in minutes.
SESSION_ENCRYPTKeep enabled to encrypt session payloads.
SESSION_SECURE_COOKIESet true after HTTPS is working.

Wrong proxy trust can make Laravel see the proxy rather than the visitor address, produce HTTP links behind HTTPS, or weaken internal-traffic and GeoIP classification.

PostgreSQL

DB_CONNECTION=pgsql
DB_HOST=postgres
DB_PORT=5432
DB_DATABASE=analytics
DB_USERNAME=analytics
DB_PASSWORD=replace-with-a-long-random-value

Keep DB_HOST=postgres for the supplied Compose stack. A native installation normally uses 127.0.0.1 or the private address of its managed database. The application database is PostgreSQL even though reporting sources may also use MySQL.

Compose explicitly selects pgsql, disables DB_URL, and uses matching database/user defaults for Laravel and PostgreSQL. Choose credentials before first startup: editing environment values does not change roles or passwords already stored in the database volume. Preserve existing credentials; see the Forge recovery steps for a mismatch.

Redis, cache, and queues

REDIS_CLIENT=phpredis
REDIS_HOST=redis
REDIS_PASSWORD=null
REDIS_PORT=6379
REDIS_QUEUE_RETRY_AFTER=90

CACHE_STORE=redis
QUEUE_CONNECTION=redis

Redis carries queues, cache, sessions, rate limits, and operational heartbeats. The supplied service enables persistence and a no-eviction policy. It is still not a replacement for PostgreSQL backups.

Mail delivery

MAIL_MAILER=log renders email behavior without delivering to an inbox. Configure any Laravel-supported production transport before enabling alerts or scheduled dashboard reports. A typical SMTP deployment also supplies host, port, username, password, encryption scheme, and sender identity.

MAIL_MAILER=smtp
MAIL_HOST=smtp.example.com
MAIL_PORT=587
MAIL_USERNAME=analytics@example.com
MAIL_PASSWORD=replace-with-provider-secret
MAIL_SCHEME=tls
MAIL_FROM_ADDRESS=analytics@example.com
MAIL_FROM_NAME="Privacy Analytics"

Use Email previews to verify presentation, then send a controlled test through the configured provider before relying on alert delivery.

Retention

VariableDefaultControls
RAW_RETENTION_DAYS90Raw browser events, event UUID ledger, and raw-age hourly detail.
AGGREGATE_RETENTION_MONTHS25Longer-lived daily analytics rollups.

Choose periods based on the questions you need to answer, expected storage growth, and your privacy policy. Reducing a value makes the next scheduled retention run eligible to remove more history.

Optional GeoIP

GEOIP_PATH=/var/www/html/storage/app/geoip/GeoLite2-City.mmdb
GEOIP_UPDATE_URL=

No location database is bundled. GEOIP_PATH should point to a compatible local MMDB file in persistent private storage. GEOIP_UPDATE_URL may contain an HTTPS URL for an MMDB or tar.gz archive; treat signed URLs and license keys as secrets. Without a valid file, collection continues and country or region stays unknown.

Logging

The default production configuration writes warnings and errors to standard error:

LOG_CHANNEL=stderr
LOG_LEVEL=warning

Send container output to a protected log platform when needed, but avoid request-body logging for collection and designer endpoints. Rotate and retain logs according to the same operational policy as the application.

Apply and verify changes

docker compose up -d --force-recreate app worker scheduler
docker compose exec -T app php artisan optimize
docker compose exec -T app php artisan analytics:check
curl --fail https://analytics.example.com/health

Check Troubleshooting if the containers restart but the health endpoint or background processes do not recover.
