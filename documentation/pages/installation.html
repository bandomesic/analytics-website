Deploy anywhere

Installation

Use the supplied Docker Compose stack for the fastest, repeatable production installation. It runs the same PHP, PostgreSQL, Redis, worker, and scheduler layout that the project tests.

1. Prepare the server

Install Docker Engine, Docker Compose v2, Git, and OpenSSL. Clone the repository into an operator-owned directory:

git clone https://github.com/bandomesic/analytics.git privacy-analytics
cd privacy-analytics
cp .env.example .env
./bin/setup

bin/setup creates cryptographically random values only for blank APP_KEY, DB_PASSWORD, and SETUP_TOKEN entries. Running it again does not rotate existing secrets.

2. Configure the environment

Edit .env before starting the containers. Keep database and Redis hostnames as their Compose service names.

APP_ENV=production
APP_DEBUG=false
APP_URL=https://analytics.example.com
APP_DOMAIN=analytics.example.com
APP_PORT=8080
SESSION_SECURE_COOKIE=true
TRUSTED_PROXIES=172.16.0.0/12

DB_CONNECTION=pgsql
DB_HOST=postgres
DB_PORT=5432
DB_DATABASE=analytics
DB_USERNAME=analytics

REDIS_HOST=redis
REDIS_PORT=6379
QUEUE_CONNECTION=redis

Replace the broad example proxy subnet with the dedicated Docker network range when possible. Never set TRUSTED_PROXIES=* on a backend that can receive untrusted traffic directly.

3. Start the stack

docker compose up -d --build
docker compose ps
docker compose logs init

The initializer waits for PostgreSQL and Redis, then runs migrations. The web app, Horizon worker, and scheduler start only after the migration succeeds. Health checks can take up to two minutes during the first build.

4. Add the reverse proxy

The application listens on 127.0.0.1:8080. Put Nginx, Caddy, Traefik, or another trusted HTTPS proxy in front of that private endpoint.

location / {
    proxy_pass http://127.0.0.1:8080;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}

If no proxy already exists, the repository includes a Caddy overlay that obtains and renews certificates:

docker compose -f docker-compose.yml -f docker-compose.caddy.yml up -d --build

Only one service may own public ports 80 and 443. Do not start the Caddy overlay when the server already has Nginx, Caddy, or a hosting control panel listening on those ports.

5. Claim the installer

Check the private and public health endpoints, then read the setup token from the project directory:

curl --fail http://127.0.0.1:8080/health
curl --fail https://analytics.example.com/health
grep '^SETUP_TOKEN=' .env

Open https://analytics.example.com/install. Enter the token, administrator details, organization, site name, and the exact HTTP or HTTPS origin of the website you will track. The installer closes permanently after completion.

i

The setup token belongs in the installer form, never in a URL. Keep it out of screenshots, shell history shared with others, tickets, and logs.

Native Laravel alternative

After provisioning the native dependencies from server requirements, configure .env for the host database and Redis services, then deploy with:

composer install --no-dev --no-interaction --prefer-dist --optimize-autoloader
npm ci
npm run build
php artisan migrate --force --no-interaction
php artisan optimize

Serve only public/ through PHP-FPM 8.5. Supervise php artisan horizon, run php artisan schedule:run every minute, and restart Horizon after each deployment with php artisan horizon:terminate.
