A few quick answers.

Can I run it on my own server?+

Yes. Privacy Analytics is designed to be self-hosted. The repository includes the application and its Docker setup.

Can I try it before installing?+

A public demo is being prepared. Until then, follow the guided tutorials to see the main workflows.Yes. Open the live demo to explore reports and sample dashboards with example data.

Can I build dashboards for different teams?+

Yes. Create tabbed dashboards, drag and resize widgets, save filters, and restore earlier versions so each team gets a focused view.

Can I connect my own data?+

Connect PostgreSQL or MySQL, or upload a CSV. Define metrics and calculated fields from those sources and use them in dashboard widgets.

How can I share results?+

Create a protected share link, export a dashboard, or schedule a recurring email report for the people who need it.
